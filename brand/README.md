# Obzio — Brand Asset Package

Production-ready logo derivatives generated from the canonical master `vectorial.ai`
(BrandBucket delivery). The mark was **not redrawn, approximated or altered**: the
renderable PDF layer of the master was empty (artwork was stored only in the embedded
Adobe Illustrator private stream), so the exact vector path coordinates were transcribed
operator-for-operator from that stream and colour-matched to the official `large.png`
export. Every derivative was verified visually against the master.

## Colours
| Token | Value |
|---|---|
| Wordmark charcoal | `#474443` |
| Symbol gradient (dark, left) | `#3E9029` |
| Symbol gradient (light, right) | `#ACCE22` |
| Symbol gradient direction | horizontal, left→right (dark→light) |

Gradient corresponds to the master's AI CMYK stops `C40 M0 Y100 K0` (light) and
`C78 M25 Y100 K0` (dark).

## Files
- `obzio-logo-full.svg` — full horizontal logo, light backgrounds (**primary**).
- `obzio-logo-full-dark.svg` — full logo, dark backgrounds (white wordmark; symbol unchanged).
- `obzio-symbol.svg` — symbol only.
- `obzio-icon.svg` / `obzio-favicon.svg` — square-canvas symbol sources (app-icon / favicon padding).
- `png/` — transparent PNGs (full logo @1024/2048, dark @2048, symbol @512/1024).
- `webp/` — WebP (full logo @2048, symbol @1024).
- `icons/` — `favicon.ico` (16/32/48), `favicon-16/32/48.png`, `icon-192/512.png`,
  `icon-maskable-512.png`, `apple-touch-icon-180.png`.
- `social/` — Open Graph 1200×630 (`obzio-og.png` light, `obzio-og-dark.png` dark, `.webp`).
- `manifest.json` — machine-readable index (dimensions, byte sizes, sha256 prefix, purpose).

## Usage surfaces
Public website · private platform · metadata/social · authentication screens · sales materials.

## Provenance & guardrails
Neutral wordmark "obzio". These assets assert **no** company number, VAT number,
legal-entity suffix, registered address or regulated claim.

## Known constraint
At 16px the four-fold mark loses its central diamond (inherent to the mark's detail);
tight favicon padding is applied to maximise legibility. The mark is intentionally **not**
simplified.
